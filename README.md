## 🧠 Overview

> **Neural Galaxy** is a dark-space themed interactive portfolio built to showcase Data Science, Machine Learning, and AI Engineering projects. The centrepiece is a fully interactive **3D AI brain** rendered with React Three Fiber — each project lives as a glowing neuron node inside the brain, connected by gold neural pathways.

## ✨ Features

- 🧠 **Interactive 3D AI Brain** — React Three Fiber + Three.js with clickable project neurons
- 🚀 **Terminal Boot Sequence** — Animated hero loader with character-by-character typing
- 🌌 **Particle Starfield** — Dynamic background with per-section tint shifts
- 💡 **Holographic Pedestal** — Sci-fi brain display platform with bloom post-processing
- 📱 **Fully Responsive** — Mobile, tablet, laptop, desktop breakpoints
- 🌙 **Dark / Light Mode** — Full theme toggle with persistent state
- ⚡ **Smooth Scroll** — Lenis smooth scroll integration
- 🔒 **Classified Project Slots** — Locked placeholder neurons for upcoming projects

## 🏃 Getting Started

```bash
# Clone the repository
git clone https://github.com/HeinHtet-Phyo/hhp-portfolio-final.git

# Install dependencies
cd hhp-portfolio-final
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
